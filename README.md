# Sant Pere, Slowly

A Hugo neighborhood guide to Sant Pere and Santa Caterina in Barcelona.

## Local preview

Install Hugo, then run:

```sh
hugo server
```

## Weekly digest

The dated digest lives in `content/news/`. Replace its front matter items with current, source-linked neighborhood reporting each week and update the issue date in `layouts/index.html`.

## Map

The interactive map uses Leaflet and OpenStreetMap tiles. Place data lives in `data/places.json`.
